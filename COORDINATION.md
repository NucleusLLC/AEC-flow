## Ground rules
- **Single-tenant placeholder track.** All data in `lib/data/<module>.ts` returning in-memory placeholder data. Swap to Prisma once Supabase is live. Never query Prisma from pages/components.
- **Don't edit a file another session owns** (see ownership below). If you need a shared file, append a note here first.
- Reuse: `components/ui/*` (Card, Badge/StatusBadge/PriorityBadge, ProgressBar), `lib/format.ts`, `lib/utils.ts`. Module-specific status colours go in `components/<module>/badges.tsx`.
- Pattern per module: `lib/data/<m>.ts` (+types, get*, summarize*) → `components/<m>/<m>-view.tsx` (client, filter/sort/table) → `app/(app)/<m>/page.tsx` (tiles + view) → optional `app/(app)/<m>/[id]/page.tsx` (detail).
