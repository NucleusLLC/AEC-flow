# AEC-flow public API v1

A small JSON API for **connected apps**: desktop add-ins (M.E.P.flow first) that
read a practice's projects and send a material take-off into it as a new draft
cost estimate.

Base URL: `https://aec-flow.com/api/v1`

## Authentication

1. An Admin or Director opens **Settings → Integrations → Connected apps**, types
   a name (for example "M.E.P.flow on the drafting PC") and clicks
   **Create token**.
2. The token is shown **once**, for example `aecf_3q9S…` (48 characters). Copy it
   into the add-in. AEC-flow keeps only its sha256, so a lost token cannot be
   recovered: revoke it and create a new one.
3. The add-in sends it on every request:

   ```
   Authorization: Bearer aecf_…
   ```

A token acts for the practice it was created in, and only that practice. Each
use updates its "Last used" date in Settings. **Revoke** stops it at once.

Every response is JSON with `Cache-Control: no-store`. There is no CORS: this
API is for desktop clients, not browser pages on other sites.

### Errors common to every endpoint

| Status | Body | When |
| --- | --- | --- |
| 401 | `{ "error": "invalid_token" }` | No `Authorization` header, a malformed token, an unknown token or a revoked one (indistinguishable on purpose) |
| 403 | `{ "error": "license_expired" }` | The token is good but the practice's AEC-flow licence has expired |
| 500 | `{ "error": "server_error" }` | Something failed on AEC-flow's side; safe to retry |

## GET /api/v1/me

Which practice the token belongs to. Use it to test a pasted token.

```bash
curl -s https://aec-flow.com/api/v1/me \
  -H "Authorization: Bearer $AECF_TOKEN"
```

```json
{ "company": { "id": "cmf…", "name": "ZenArch" }, "token": { "name": "M.E.P.flow on the drafting PC" } }
```

## GET /api/v1/projects

The practice's projects, newest first. Archived projects are left out.
`number` is the project number; `client` is the client's name, or `null`.

```bash
curl -s https://aec-flow.com/api/v1/projects \
  -H "Authorization: Bearer $AECF_TOKEN"
```

```json
{
  "projects": [
    { "id": "cmg…", "number": "ZA-2026-014", "name": "Villa Verde", "client": "Ms Vega" }
  ]
}
```

## POST /api/v1/estimates/import

Creates a new **DRAFT** cost estimate from a take-off. It carries quantities
only: every unit cost is 0 and every code empty, for the estimator to price in
AEC-flow against the practice's own price book.

```bash
curl -s -X POST https://aec-flow.com/api/v1/estimates/import \
  -H "Authorization: Bearer $AECF_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "source": "M.E.P.flow",
    "sourceVersion": "1.0.0-beta.18",
    "projectId": null,
    "title": "M.E.P.flow take-off — Drawing1.dwg",
    "currency": "USD",
    "categories": [
      { "name": "Drain · PVC",
        "items": [ { "task": "Pipe", "size": "DN100", "qty": 12.5, "unit": "m", "note": "" } ] }
    ]
  }'
```

`201 Created`:

```json
{ "id": "cmh…", "url": "https://aec-flow.com/estimates?project=cmh…" }
```

`url` opens the new estimate in the app (the user must be signed in).

### Body

| Field | Type | Notes |
| --- | --- | --- |
| `source` | string, required | The add-in's name, e.g. `"M.E.P.flow"` |
| `sourceVersion` | string, optional | The add-in's version |
| `projectId` | string or null, optional | An id from `GET /projects`. Absent or null: the estimate is not filed under a project |
| `title` | string, required | The take-off's title |
| `currency` | string, optional | Three-letter code; default `"USD"` |
| `categories` | array, required | At most 200; each becomes one section, in order |
| `categories[].name` | string, required | Section name |
| `categories[].items` | array, required | Each becomes one line, in order; at most 5000 lines in all |
| `items[].task` | string, required | |
| `items[].size` | string, optional | Appended to the task: `"Pipe" + "DN100"` → `"Pipe DN100"` |
| `items[].qty` | number, required | Finite, 0 or more |
| `items[].unit` | string, optional | Default `"no"` (number of) |
| `items[].note` | string, optional | Appended to the line: `"Pipe DN100 — <note>"` |

Every string is at most 300 characters; the whole body at most 1 MB.

### What the estimate gets

- **With `projectId`**: the project's number, name, client and site address. If
  the project has no estimate yet, this one becomes the project's estimate (it
  appears on the project's Estimate tab); otherwise it is an additional draft
  and the existing estimate is not touched.
- **Without**: the `title` is the estimate's name; no project or client is linked.
- `source`, `sourceVersion` and `title` are kept with the estimate as its import
  record.

### Errors

| Status | Body | When |
| --- | --- | --- |
| 400 | `{ "error": "bad_request", "message": "categories.0.items.3.qty: items[].qty must not be negative" }` | The body is not JSON, is over 1 MB, or breaks a rule above. `message` names the first problem |
| 404 | `{ "error": "project_not_found" }` | `projectId` is not a project of this practice |
